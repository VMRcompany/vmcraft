Серверы Java Edition

VMcraft запускает Minecraft: Java Edition, поэтому вы заходите на те же серверы, что и с компьютера.

Как зайти

1

Войдите в аккаунт

Для серверов с online-mode нужен вход через Microsoft.

2

Поставьте ту же версию

Версия (и моды, если сервер модовый) должна совпадать с сервером.

3

Добавьте адрес

В игре: Мультиплеер → Добавить сервер → IP и порт.
